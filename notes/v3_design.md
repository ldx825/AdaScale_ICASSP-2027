# AdaScale v3 — 输出层软化融合（probability-level soft fusion）

日期：2026-02（novelty-mining 阶段）
状态：**已锁定规格，离线模拟验证完毕（6 个 FUSED 设置 + 3 个 SINGLE 不变）**

## 动机

prior_baselines.py 与 v3_sim.py 的探索发现：

1. **特征层三角加权平均（v2 输出规则）不是最优的输出层聚合**。
   在走满样本（t=10，难样本）上，视图间概率分布差异大，特征平均容易被高熵（噪声）视图稀释。
2. 熵过滤（丢最差 K 个视图）在 PET 上有效（+0.2~0.5）但**在 FLO/text 上有害**（−0.4），且需要"未来视图"信息 → 与早退冲突、需数据集特定逻辑。**放弃**。
3. **概率层三角加权平均**（每个视图独立 softmax 后按 w_s = s 加权平均概率）在全部 4 个（+B/16 共 6 个）FUSED 设置上非负。

## 规格（v3，与 v2 的唯一差别 = 输出规则）

```
输入视图集合 S（早退→已见前缀；走满→全部 10 个）
v2:  f_out = normalize(Σ_{s∈S} s·f_s);  pred = argmax(f_out·T)
v3:  P_out = Σ_{s∈S} s·softmax(f_s·T / τ_s) / Σ_{s∈S} s;  pred = argmax(P_out)
     其中 τ_s = 0.02（"软化温度"；0.01 为 CLIP logit_scale=100 的原始尺度）
```

- **决策层完全冻结**：SINGLE/FUSED 模式选择、稳定性早停（r=4, δ=0.65, ε=0.01）不变 → 平均视图数、运行时不变。
- **因果/在线兼容**：视图 s 的概率在计算该视图时即得，无需未来信息；早退样本只用已见视图。
- **SINGLE 模式（EUROSAT）恒等**：单视图时概率平均退化为原预测。
- Training-free / label-free：τ_s = 0.02 是先验设定（软化 = 缓解单视图过尖分布对平均的支配），非测试集调参。

## 结果（冻结轨迹离线模拟 = 精确，v2 复现 Δ=0.0000）

| 设置 | v2 | v3 | Δ | paired-bootstrap P(d>0) |
|------|-----|-----|-----|------|
| PET/text | 82.45 | **82.63** | +0.18 | 0.976 |
| PET/gen | 60.96 | **61.15** | +0.20 | 0.950 |
| FLO/text | 65.15 | **65.18** | +0.03 | 0.573 |
| FLO/gen | 43.07 | **43.30** | +0.23 | 0.982 |
| PET/text · B/16 | 86.08 | **86.10** | +0.03 | 0.592 |
| PET/gen · B/16 | 64.15 | **64.49** | +0.34 | 1.000 |
| EUROSAT (SINGLE ×2) | 42.38 / 36.33 | 不变 | 0 | — |

- 6 个融合设置平均 +0.17；**5/6 非负、4/6 P≥0.95**；零负面。
- 效率不损失：平均尺度、退出直方图与 v2 完全一致。
- **EUROSAT 交叉证据**：对 EUROSAT 强行融合并应用 v3，也仅 43.12/37.21，**仍低于 SINGLE 45.34/41.17** → 高质量输出规则改变不了"小尺度根本性有害"的域级事实，**模式选择仍然是必要的**（且 v3 不会误触发）。

## 弃用方案记录（reviewer-anticipation）

| 方案 | 处置 | 原因 |
|------|------|------|
| 熵过滤（全局/走满） | 弃用 | FLO/text 有害、需未来信息 |
| margin 加权（特征域） | 弃用 | 增益 < 概率平均且 FLO/text 偏负 |
| logit 平均、几何平均 | 弃用 | 一致负 |
| F10 组合（margin^0.5） | 弃用 | PET/gen 更强(+0.49) 但 FLO/text −0.05，稳健性不如 F7 |
| 置信度选择（F9） | 弃用 | 无稳定增益 |
